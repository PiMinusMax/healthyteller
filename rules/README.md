# Regelwerk

Eine YAML-Datei pro Regel. Format und Beispiel stehen in [docs/auftrag.md](../docs/auftrag.md), Abschnitt „Regelwerk“.

Jede Regel nennt ihre Quellen und hat Referenzfälle innerhalb und außerhalb der Schwelle. Ausgeliefert wird sie erst mit `status: reviewed` nach fachlicher Freigabe.
